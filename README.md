# Mendeleev Dice Simulator (멘델리예프 다이스 시뮬레이터)

A beautiful web-based TRPG dice simulator with chemistry-themed design that matches dice roll results with periodic table elements.

## � Features

- **7 Types of TRPG Dice**: d4, d6, d8, d10, d12, d20, d100
- **Animated Dice Rolling**: Visual feedback with smooth animations
- **Mathematical Combinations**: Calculates all possible combinations using:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×) - optional
  - Division (÷) - optional
- **Periodic Table Integration**: Each calculation result is matched with corresponding chemical elements
- **Chemistry-themed Design**: Beautiful gradient effects and modern UI

## 🚀 How to Use

1. Open `index.html` in a web browser
2. Select the dice you want to roll by clicking the checkboxes
3. Optionally enable multiplication and division operations
4. Click "Roll Dice" button
5. View your dice results and all possible mathematical combinations
6. Each result shows the corresponding chemical element symbol and name
