# 멘델리예프 다이스 시뮬레이터

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Web App](https://img.shields.io/badge/Web-App-blue.svg)](https://github.com)
[![Chemistry](https://img.shields.io/badge/Chemistry-Education-green.svg)](https://github.com)

🧪 **화학 원소와 주사위를 결합한 독창적인 TRPG 시뮬레이터**

## 🎯 개요

멘델리예프 다이스 시뮬레이터는 TRPG(테이블탑 롤플레잉 게임)의 7종 주사위(d4, d6, d8, d10, d12, d20, d100)를 사용하여 화학 원소를 탐구하는 교육용 웹 애플리케이션입니다. 주사위 결과를 통해 계산된 값들을 주기율표의 원소번호와 매칭하여 화학 학습을 재미있게 만들어줍니다.

## ✨ 주요 기능

### 🎲 주사위 시스템
- **7종 TRPG 주사위 지원**: d4, d6, d8, d10, d12, d20, d100
- **선택적 주사위 굴리기**: 원하는 주사위만 선택하여 사용
- **실시간 애니메이션**: 주사위 굴리기 시 생동감 있는 애니메이션 효과
- **키보드 단축키**: 스페이스바로 빠른 주사위 굴리기

### 🧮 계산 시스템
- **기본 연산**: 덧셈(+), 뺄셈(-) 
- **확장 연산**: 곱셈(×), 나눗셈(÷) - 토글 옵션으로 활성화
- **다양한 조합**: 단일 값, 두 개 조합, 세 개 이상 조합
- **자동 중복 제거**: 동일한 결과값 자동 필터링

### 🧬 원소 정보 시스템
- **완전한 주기율표**: 118개 원소 전체 데이터 지원
- **상세 정보**: 원자번호, 원소기호, 원소명, 원자량, 원소 분류, 주기
- **시각적 표현**: 원소별 고유 색상과 그래픽 요소
- **인터랙티브 모달**: 원소 클릭 시 상세 정보 표시

### 🎨 사용자 경험
- **화학 테마 디자인**: 원소와 화학 실험을 연상시키는 수려한 UI
- **반응형 디자인**: 모든 디바이스에서 완벽한 사용 경험
- **실시간 검색**: 원소 기호, 이름, 계산식으로 결과 필터링
- **부드러운 애니메이션**: 페이드인, 스케일, 회전 등 다양한 효과

## 🚀 사용 방법

### 1. 주사위 선택
- 원하는 주사위들을 체크박스로 선택
- 최소 1개 이상의 주사위 선택 필요
- 선택된 주사위는 시각적으로 강조 표시

### 2. 연산 옵션 설정
- 기본: 덧셈, 뺄셈만 사용
- 확장: 곱셈, 나눗셈 추가 (토글 버튼으로 활성화)

### 3. 주사위 굴리기
- "주사위 굴리기" 버튼 클릭 또는 스페이스바 입력
- 애니메이션과 함께 결과 표시
- 자동으로 계산 및 원소 매칭

### 4. 결과 탐색
- 계산 결과와 해당 원소 정보 확인
- 원소 기호 클릭으로 상세 정보 모달 열기
- 검색 기능으로 특정 원소나 계산식 찾기
